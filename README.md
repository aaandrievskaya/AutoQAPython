# Мой Python-проект (очередной, кек)

## Структура проекта
Каждая ветка посвящена следующему спринту
Каждый программный файл с расширением py посвящен странице с задачами "практика" после очередной темы урока и назван соответствующе (переведен на английский)
каждая задача из практики оформлена как функция. В блоке с вызовом функций для удоства необходимо закоменчивать те функции-задачи, которые сейчас не проверяются
