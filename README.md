# Мой Python-проект

## Требования

- Python 3.8 или выше
- Git (для клонирования)

## Создание виртуального окружения

1. Откройте терминал в корне проекта и выполните:
python -m venv .venv
2. Активируйте окружение:
.\.venv\Scripts\Activate.ps1
3. При активном виртуальном окружении выполните:
pip install -r requirements.txt

## Установка зависимостей
При активном виртуальном окружении выполните:
pip install -r requirements.txt

## Запуск тестов
Убедитесь, что виртуальное окружение активно, затем выполните:
pytest

Есть опция для запуска только тестов из карточки 3.3. Для этого необходимо выполнить команду с маркером:
pytest -m for3_3 -v

Тесты должны пройти успешно, выведя 10 passed.
