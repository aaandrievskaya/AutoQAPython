# Мой Python-проект

## Требования

- Python 3.8 или выше
- Git (для клонирования)

## Создание виртуального окружения

1. Откройте терминал в корне проекта и выполните:
python -m venv .venv
2. Активируйте окружение:
.\.venv\Scripts\Activate.ps1
3. При активном виртуальном окружении выполните:
pip install -r requirements.txt

## Установка зависимостей
При активном виртуальном окружении выполните:
pip install -r requirements.txt

## Запуск тестов
Убедитесь, что виртуальное окружение активно, затем выполните:
pytest

Тесты должны пройти успешно, выведя 1 passed.
