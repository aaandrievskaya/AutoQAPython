# Мой Python-проект (очередной, кек)

## Структура проекта
Каждая ветка в проекте посвящена следующему спринту

В ветке помимо прочих файлов хранятся папки, посвященные большим разделам спринта (карточкам)

В папках карточек каждый программный файл с расширением py посвящен странице с задачами "практика" после очередной темы урока и назван соответствующе (переведен на английский). Для удобства также пронумерован.

Каждая задача из практики оформлена как функция. В блоке с вызовом функций необходимо оставить не закоментированной ту задачу, которая сейчас проверяется
